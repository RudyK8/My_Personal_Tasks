Couleurs principales:
    Thème clair: 
        Bleu principal -> #1764E8 : Boutons, liens, éléments actifs
        Bleu profond -> #14264D : Titres importants et navigation
        Fond général -> #F4F6FC : Arrière-plan de l'application
        Surface -> #FFFFFF : Cartes, menus et fenêtres
        Bordure -> #DFE5F1 : Séparations et contours
        Texte secondaire -> #65728A : Descriptions et informations secondaires

Couleurs fonctionnelles:
    Vert : Terminé, réussite, validation
    Orange : Attention, priorité moyenne
    Rouge : Urgence, retard, priorité haute
    Violet : Éléments secondaires, catégories

Formes et composants:
    Cartes avec coins arrondis et rayon homogène.
    Bordures discrètes.
    Icônes simples et reconnaissables.
    Boutons bleus pour actions principales.
    Animations courtes lors des interactions.
    Typographie moderne et lisible (*Inter* par exemple)
